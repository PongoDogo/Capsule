# Capsule

Μια γρήγορη μπάρα για snippets, αναζήτηση αρχείων και καθημερινές ενέργειες στα Windows.

**Η πρώτη δημόσια δοκιμαστική έκδοση βρίσκεται σε προετοιμασία. Δεν υπάρχει ακόμη εγκεκριμένο αρχείο λήψης.** Τα αποτελέσματα σε υπολογιστή ανάπτυξης δεν αποτελούν εγγύηση λειτουργίας σε κάθε PC.

Ο αρχικός στόχος είναι Windows 11 x64. Η έκδοση Mac θα σχεδιαστεί ξεχωριστά.

Η προετοιμασία περιλαμβάνει installer στα ελληνικά/αγγλικά, προαιρετικά Everything και QuickLook, ιδιωτικό AutoHotkey helper και επαληθευμένες ενημερώσεις με επανεκκίνηση κατόπιν επιλογής σου. Η λειτουργία ελληνικού OCR και οι δοκιμές σε καθαρό PC πρέπει να ολοκληρωθούν πριν διατεθεί πλήρης beta.

Ο δημιουργός είναι ο **PongoDogo**. Επικοινωνία: [webuildreal@gmail.com](mailto:webuildreal@gmail.com).

Ο χώρος αυτός προορίζεται για downloads, σημειώσεις εκδόσεων και υποστήριξη. Ο πηγαίος κώδικας του Capsule παραμένει ιδιωτικός. Οι άδειες και οι τυχόν απαιτούμενες πηγές των ξεχωριστών εργαλείων τρίτων θα συνοδεύουν την αντίστοιχη διανομή.
